`tools/make_description.py`, so the numbers and wording match the README.

## The description

It uses only what the site's editor itself writes: paragraphs, headings, bold and italic, bullet and numbered lists, and
the site's own **spoiler** (the same kind as the one under the intro on the Deciduous Trees page). There is no custom
layout. Paste `docs/moddb-description.html` in the editor's HTML / source view if it has one.

The screenshots inside the spoiler point at the repository's copies, which load once the repository is public. Until then
(or if you would rather host them on the Mod DB), upload the two screenshots to the page, then in the spoiler replace the
two image addresses with the uploaded ones, or delete the images and re-insert them with the editor's image button.
